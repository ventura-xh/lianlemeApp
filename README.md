
# 练了么(LianlemeApp)

基于 Kotlin + Jetpack Compose 构建的Android健身辅助应用。
完全vibe coding

## 核心功能

### 1. 训练计划管理
*   **计划制定**：创建自定义训练计划，支持添加动作、设置组数、重量、次数。
*   **动作库**：内置丰富的预设动作库，涵盖多种肌肉群和训练类别。支持按肌肉或类别筛选。
*   **动作编辑**：支持自定义添加新动作，或重置预设动作库。

### 2. 训练执行
*   **实时执行**：在执行计划时提供清晰的界面，跟踪每组训练的完成状态（重量、次数）。
*   **计时器**：
    *   **训练计时器**：自动记录训练总时长。
    *   **休息计时器**：组间休息倒计时，支持语音提示和振动提醒。
    *   **悬浮窗**：训练过程中可呼出计时器悬浮窗，不影响其他操作。
*   **恢复训练**：意外退出或切到后台后重启，应用会提示恢复上一次训练进度。

### 3. 训练记录与统计
*   **日历视图**：直观展示每日的训练记录。
*   **统计报表**：按月生成训练报告，统计训练次数、总时长、动作分布、肌肉群覆盖等数据。
*   **单次详情**：查看每次训练的详细完成情况（每组重量、次数）。

### 4. 个人数据管理
*   **身体数据**：记录体重、身高、BMI、体脂率、肌肉量等指标，以及身体围度（胸、腰、臀、臂、腿）。
*   **体脂计算器**：内置美军方三点头和七点法体脂计算公式，辅助评估身体成分。
*   **RM 计算器**：输入重量和次数，快速估算 1RM (一次最大重量)，并生成常用次数对照表。

## 🚀 快速开始

### 环境要求
*   Android Studio Hedgehog (2023.1.1) 或更高版本。
*   JDK 17。
*   Android SDK (minSdk 26, targetSdk 34)。

### 构建步骤
1.  克隆仓库到本地。
2.  在 Android Studio 中打开项目根目录下的 `build.gradle.kts`。
3.  等待 Gradle 同步完成。
4.  连接设备或启动模拟器，点击 Run 按钮运行。
